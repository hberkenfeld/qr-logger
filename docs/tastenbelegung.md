# QR-Logger – Standard-Tastenbelegung (angelehnt an DXLog)

Quelle: [DXLog – Keyboard and text functions](https://dxlog.net/docs/index.php/Keyboard_and_text_functions). Alle Tasten sind umbelegbar (KeyMap).

**Linux-Hinweis:** `Ctrl+Alt+F1…F12` schaltet unter Linux die virtuellen Konsolen um und erreicht die Anwendung meist nicht. Diese Kombinationen bekommen in QR-Logger Ersatzbelegungen.

## Eingabezeile

| Taste | Funktion |
|---|---|
| Enter | QSO loggen bzw. bei ESM die passende Nachricht senden |
| Space | nächstes Feld (überspringt RST) |
| Tab | nächstes Feld (inkl. RST) |
| Alt-W / F11 | QSO löschen, zurück ins Rufzeichenfeld (leeres Feld: letztes Call zurückholen) |
| Ctrl-W | aktuelles Feld leeren |
| Ctrl-K | ab Cursor bis Feldende löschen |
| Ctrl-+ | still loggen (ohne Nachricht) |
| Ctrl-Alt-+ | Loggen erzwingen (ohne Prüfung) |
| Ctrl-Z | QSO-Änderung rückgängig |
| Alt-N | QSO-Notiz |
| Ctrl-X | X-QSO markieren |

## Nachrichten / Betrieb

| Taste | Funktion |
|---|---|
| F1 | CQ (Run) / eigenes Call (S&P) |
| F2 | Exchange |
| F3 | Serial / TU |
| F4 | eigenes Call |
| F5 | geloggtes Call |
| F6 | Wiederholung anfordern |
| F7 | „?“ |
| Insert | Call + Exchange |
| + (Keypad +) | TU + loggen |
| Shift-F1…F7, Shift-Insert, Shift-+ | **SSB: aufnehmen** · CW/RTTY: Text bearbeiten |
| Esc | Senden abbrechen |
| Ctrl-M | ESM ein/aus |
| Ctrl-R | CQ-Wiederholung |
| Ctrl-Tab | Run/S&P umschalten (Fokus-Kanal) |
| Shift-Ctrl-Tab | Run/S&P umschalten (anderer Kanal) |
| Alt-K | Keyboard-Mode (CW/RTTY direkt tippen) |
| Alt-V | CW-Tempo eingeben |
| Alt-F9 / Alt-F10 | CW −/+ 2 WpM (Fokus-Kanal) |
| Shift-Alt-F9 / F10 | CW −/+ 2 WpM (anderer Kanal) |
| Alt-C | Zusatznachrichten |

## Radiosteuerung

| Taste | Funktion |
|---|---|
| Alt-F1 / Alt-F2 | Band runter / hoch |
| Ctrl-F1 / Ctrl-F2 | Mode wechseln |
| Alt-F4 | CQ-Frequenz ↔ letzte Frequenz |
| Shift-Alt-F4 | zurück auf CQ-Frequenz, Run |
| Shift-↑ / Shift-↓ | RIT (Run) bzw. Frequenz (S&P) |
| Shift-Del | RIT löschen |
| Alt-↑ / Alt-↓ | Frequenzschritt |
| Ctrl-T | Tune |
| − (Keypad −) | Split |

## SO2R / SO2V

| Taste | Funktion |
|---|---|
| ↑ / ↓ | Eingabefokus zwischen Kanälen wechseln |
| Keypad * | aktiven Kanal/VFO wechseln |
| Alt-Keypad * | Frequenz/Mode zwischen Kanälen tauschen |
| Keypad / | VFO-Knopf-Fokus (SO2V) |
| Shift-Ctrl-F1 | Kanal 1 fokussieren, Run, CQ senden |
| Ctrl-Alt-A / Ctrl-Alt-T | Kanal 1 / 2 auf beide Ohren |
| Ctrl-Alt-S | beide Kanäle hören (Stereo) |
| Ctrl-Alt-L | Fokus-Kanal auf beide Ohren |
| Ctrl-Alt-1…8 | SO2R-Szenario wählen |

## Bandmap / Fenster

| Taste | Funktion |
|---|---|
| Ctrl-Enter | Spot einfügen |
| Ctrl-↑ / Ctrl-↓ | nächsten Spot darüber/darunter übernehmen |
| Ctrl-Shift-↑ / ↓ | nächsten Multi-Spot übernehmen |
| Ctrl-Space | Spot nahe aktueller Frequenz übernehmen |
| F8 / F9 / F10 / F12 | Check N+1 / Check Call / Multis / Partials |
| Alt-F3 | Spot senden |
